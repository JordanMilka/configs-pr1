# Эмулятор командной оболочки (вариант 8, этап 1)

## 1. Общее описание

Учебный проект по дисциплине «Конфигурационное управление».
Разрабатывается эмулятор языка оболочки ОС, работа которого
максимально похожа на работу в командной строке UNIX-подобной
системы.

Текущая версия соответствует **этапу 1 «REPL»** — это минимальный
прототип с графическим интерфейсом. Большинство команд пока
являются заглушками: они выводят своё имя и полученные аргументы,
но диалог с пользователем уже полностью поддерживается.

Что реализовано на этапе 1:

- графический интерфейс на библиотеке `tkinter` (входит в
  стандартную поставку Python);
- заголовок окна формируется по данным реальной ОС в формате
  `Эмулятор - [username@hostname]`;
- парсер ввода с раскрытием переменных окружения реальной ОС
  (`$HOME`, `${HOME}`);
- команды-заглушки `ls` и `cd`;
- команда `exit`, завершающая работу эмулятора;
- сообщения об ошибках: неизвестная команда, неверные аргументы,
  ошибка разбора строки.

Виртуальная файловая система (VFS), параметры командной строки и
реальная логика команд появятся на следующих этапах.

### Структура репозитория

```
.
├── README.md          документация проекта
├── .gitignore         исключения для Git

```

Требования к окружению: Python 3.8 или новее с модулем `tkinter`.
Внешние зависимости не используются.

## 2. Описание всех функций и настроек

### Модуль `src/parser.py`

Отвечает за разбор строки, введённой пользователем.

| Функция | Назначение |
| --- | --- |
| `is_name_symbol(symbol)` | Проверяет, допустим ли символ в имени переменной (буква, цифра или `_`). |
| `read_plain_name(text, start)` | Читает имя переменной без фигурных скобок, возвращает имя и позицию после него. |
| `read_braced_name(text, start)` | Читает имя переменной в фигурных скобках. При отсутствии `}` возбуждает `ParseError`. |
| `read_variable_name(text, start)` | Выбирает подходящий способ чтения имени переменной. |
| `expand_variables(text)` | Раскрывает в строке переменные окружения вида `$NAME` и `${NAME}`. |
| `parse_line(line)` | Раскрывает переменные и делит строку на список токенов: команда и её аргументы. |

Правила раскрытия переменных:

- `$NAME` — имя читается до первого символа, не являющегося буквой,
  цифрой или знаком подчёркивания;
- `${NAME}` — имя ограничено фигурными скобками, что позволяет
  писать `${HOME}bin` без пробела;
- неизвестная переменная заменяется пустой строкой (как в UNIX);
- одиночный знак `$` выводится без изменений;
- незакрытая фигурная скобка приводит к ошибке `ParseError`.

Исключение `ParseError` сообщает об ошибке разбора строки.

### Модуль `src/commands.py`

Содержит команды эмулятора.

| Функция | Назначение |
| --- | --- |
| `format_stub(name, arguments)` | Формирует ответ команды-заглушки из имени команды и её аргументов. |
| `command_ls(arguments)` | Заглушка `ls`. Выводит имя команды и все аргументы. |
| `command_cd(arguments)` | Заглушка `cd`. Принимает не более одного аргумента. |
| `command_exit(arguments)` | Завершает работу эмулятора. Аргументы не принимает. |
| `execute(tokens)` | Находит команду в словаре `COMMANDS` и вызывает её обработчик. |

Исключения модуля:

- `CommandError` — неизвестная команда или неверные аргументы;
- `ExitRequested` — запрос на завершение работы эмулятора.

Константы-настройки:

| Константа | Значение | Назначение |
| --- | --- | --- |
| `MAX_CD_ARGUMENTS` | `1` | Максимальное число аргументов команды `cd`. |
| `MAX_EXIT_ARGUMENTS` | `0` | Максимальное число аргументов команды `exit`. |
| `COMMANDS` | словарь | Соответствие имени команды и её обработчика. |

Чтобы добавить новую команду, достаточно написать функцию с одним
аргументом-списком и зарегистрировать её в словаре `COMMANDS`.

### Модуль `src/gui.py`

Реализует графический интерфейс.

| Функция или метод | Назначение |
| --- | --- |
| `get_user_name()` | Возвращает имя текущего пользователя ОС. |
| `build_title()` | Формирует заголовок окна вида `Эмулятор - [username@hostname]`. |
| `EmulatorWindow.__init__(master)` | Создаёт область вывода, поле ввода и привязывает клавишу Enter. |
| `EmulatorWindow.place_widgets()` | Размещает виджеты в окне. |
| `EmulatorWindow.write(text)` | Добавляет строку в область вывода и прокручивает её вниз. |
| `EmulatorWindow.on_enter(event)` | Обрабатывает нажатие Enter: повторяет ввод в диалоге и запускает выполнение. |
| `EmulatorWindow.run_line(line)` | Разбирает строку, сообщает об ошибках разбора. |
| `EmulatorWindow.run_command(tokens)` | Выполняет команду, выводит результат или сообщение об ошибке. |

Константы-настройки интерфейса:

| Константа | Значение | Назначение |
| --- | --- | --- |
| `OUTPUT_HEIGHT` | `24` | Высота области вывода в строках. |
| `OUTPUT_WIDTH` | `80` | Ширина области вывода в символах. |
| `PROMPT` | `"$ "` | Приглашение к вводу в области диалога. |
| `WELCOME` | текст | Приветственное сообщение при запуске. |

Заголовок окна и имя пользователя берутся из реальной ОС при помощи
модулей `getpass` и `socket`. Если имя пользователя получить не
удалось, используется значение `user`.

### Модуль `src/main.py`

Функция `main()` создаёт корневое окно `Tk`, объект
`EmulatorWindow` и запускает цикл обработки событий.

Параметры командной строки на этапе 1 не поддерживаются, они будут
добавлены на этапе 2.

## 3. Команды для сборки проекта и запуска тестов

Отдельная сборка не требуется: проект написан на Python и не
использует внешних библиотек. Нужен только установленный Python 3.8
или новее с модулем `tkinter`.

Проверка окружения:

```bash
python3 --version
python3 -c "import tkinter"
```

Если `tkinter` не установлен, в Debian или Ubuntu его можно
поставить командой `sudo apt install python3-tk`.

Запуск эмулятора:

```bash
# Linux, macOS
./run.sh

# Windows
run.bat

# напрямую, из корня репозитория
python3 -m src.main

# через Makefile
make run
```

Запуск тестов:

```bash
# из корня репозитория
python3 -m unittest discover -s tests -t . -v

# через Makefile
make test
```

Ожидаемый результат: `Ran 15 tests ... OK`.

## 4. Примеры использования

### Пример 1. Команды-заглушки

После запуска открывается окно с заголовком
`Эмулятор - [ivanov@laptop]`. Диалог в окне:

```
Эмулятор оболочки. Доступны команды: ls, cd, exit.
$ ls
ls: аргументы отсутствуют
$ ls -l /etc
ls: -l /etc
$ cd /home
cd: /home
```

### Пример 2. Раскрытие переменных окружения

```
$ ls $HOME
ls: /home/ivanov
$ cd ${HOME}
cd: /home/ivanov
$ ls ${HOME}/documents
ls: /home/ivanov/documents
$ ls $NO_SUCH_VARIABLE
ls: аргументы отсутствуют
$ ls price $ 5
ls: price $ 5
```

### Пример 3. Обработка ошибок

```
$ pwd
pwd: команда не найдена
$ cd one two
cd: слишком много аргументов
$ exit now
exit: команда не принимает аргументов
$ ls ${HOME
ошибка разбора: не закрыта фигурная скобка в имени переменной
```

### Пример 4. Завершение работы

```
$ exit
```

Окно эмулятора закрывается, программа завершается.

## Оформление коммитов

История коммитов ведётся по спецификации Conventional Commits:
`<тип>(<область>): <описание>`.

Примеры коммитов этапа 1:

```
feat(parser): добавить раскрытие переменных окружения
feat(commands): добавить заглушки ls, cd и команду exit
feat(gui): добавить окно эмулятора с полем ввода команд
test(parser): добавить тесты разбора строки ввода
docs(readme): описать функции, настройки и примеры запуска
```
